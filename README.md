# 宫建宇 · 艺术家作品集

黑白灰编辑式作品集，主标题使用本地阿里巴巴普惠体，包含作品大图、沉浸观展、艺术家简介、展览搜索及评论文献。无需安装依赖。

## 启动

```sh
cd /workspace/my-first-project
python3 -m http.server 8000 --bind 0.0.0.0
```

## 内容维护

- `index.html`：个人简介、展览、发表、评论与联系信息。
- `app.js`：作品数据，包括图片路径、标题、尺寸、材料与展览记录。
- `exhibition.js`：展厅、作品切换与沉浸浏览。
- `monograph.js`：展览档案搜索与导航。
- `style.css`：响应式黑白灰主题；作品图片保留原色和完整比例。
- `assets/`：艺术家上传的照片、作品与本地字体。旧 SVG 为早期示意素材，当前页面不再展示。
