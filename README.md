# 林间 · 艺术家作品集

无需安装依赖的静态作品集，包含响应式布局、作品分类、作品详情弹窗和键盘浏览。

## 本地启动

```sh
cd /workspace/my-first-project
python3 -m http.server 8000 --bind 0.0.0.0
```

浏览器打开本地 8000 端口。也可将本目录部署到支持静态网站的托管服务。

## 替换内容

- `index.html`：艺术家姓名、简介、邮箱；邮箱目前为示例。
- `app.js`：作品标题、年份、分类、尺寸与说明。
- `assets/`：本地 SVG 示例插画，可替换为真实作品并同步修改图片路径。
- `style.css`：布局、颜色与字体；无需外部字体或图片服务。

当前姓名、简介和画作均为演示内容，不代表真实艺术家资料。尚未部署到公网。
